# Original Beta UI assets

Pinned source: Andreatz/Arkamon-Beta commit `7ec91d1f4e3e5252317044b1ee300b8b3e4d80a7`. `tools/import_beta_ui.py` imports every original `public/ui/` file without rewriting images or SVG paths. No AI generation occurs.

## Reproduce

Requires Python3.10+, Pillow, and `fonttools[woff]==4.62.1`. Run `python tools/import_beta_ui.py --fonttools-dir <external-python-dependency-directory>`. Cached originals can be reproduced without network using `--cache-only`. Source copies are kept outside the repo at `../tmp/beta-ui-reference`; downloads also use the commit-specific OS temporary cache. No Godot editor/import is launched. Pass `--ffmpeg <external-ffmpeg.exe>` to decode the original title first frame and transcode the original8second1280×720/24FPS footage to Godot OggTheora. The sourceMP4 remains outside the repo; no new frames or artwork are generated. `data/site_theme.json` and `data/portrait_metadata.json` preserve the original authored theme geometry and portrait framing byte for byte.

## Layout findings

The48 player-kit SVG files are individual UI components, not1920×1080 screen designs. Their original viewBox and intrinsic dimensions are in data/ui_original.json. For example panel-wide is2026×709, panel-medium1161×423, card-portrait433×458. The website uses them as CSS border-image with center fill and stretch, preserving borders while resizing panels.

The original player-ui/kit.tsx specifies source slices: panel-wide163, panel-medium97, button-primary44, button-default48, card-default61, card-selected-violet58, card-selected-cyan56, slot-default62, slot-selected60, slot-cyan62, card-portrait99. Generic panels draw25px borders; buttons draw11px top/bottom and18px left/right. GameButton danger uses command-cancel with slice42. Hover brightness1.12, disabled opacity.45 and pressed scale.95 come directly from CSS.

The active site font is Arkamon Norwester for body/headings/buttons, defined in src/index.css from the original studio WOFF2. Chela One is also shipped but is not the active global font in the pinned source. assets/fonts/Norwester.ttf is a deterministic SFNT decode of that WOFF2 for Godot; no glyphs, metrics or styling are redesigned. Original Norwester.woff2 and ChelaOne-Regular.ttf are retained.

51 original TSX/TS/CSS/JSON reference files are copied outside the repository under ../tmp/beta-ui-reference. The studio Blu/Scuro/Comuni SVGs and original battle PNG widgets are retained alongside the48 player-kit assets, preserving all original layers/alpha/canvas sizes.
