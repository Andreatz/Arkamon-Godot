# Asset provenance

Imported from [https://github.com/Andreatz/Arkamon-Beta](https://github.com/Andreatz/Arkamon-Beta) at commit `7ec91d1f4e3e5252317044b1ee300b8b3e4d80a7`. All requests use immutable raw URLs at that commit; the old local Beta reference is not used.

## Reproducing the import

Requires Python 3.10+ and Pillow. Run `python tools/import_beta_assets.py --skip-animations` to import all raw game tables, 110 portraits, world geometry/images, two player portraits and generic type VFX. Run `python tools/import_beta_assets.py --animations-only` for the complete available original character animations. With no flags both stages run. To refresh only the higher-resolution idle sheets, run `python tools/import_beta_assets.py --animations-only --animation-states idle --cache-only`; `--species 1 5 9` can further restrict the animation selection. Unselected states remain unchanged in the manifest. Network/processing concurrency defaults to four workers (`--workers 4`). Original downloads are cached outside the repository under the OS temporary directory `arkamon-beta-godot-cache/<commit>/`. No clone or ffmpeg is required.

This run used Pillow 12.3.0. Exact processed bytes depend on the Pillow/WebP build; upstream SHA-256 values do not. The complete machine-readable audit, including immutable source URLs, input/output SHA-256 values, byte counts and transformations, is `data/import_manifest.json`.

## Coverage and transformations

- Complete original data: pokemon, mosse, tipi, crescita_hp, mappe, incontri and allenatori copied byte for byte.
- All 110 original transparent front portraits: crop nonzero-alpha bounds, Lanczos resize to fit464×464, place on512×512 transparent canvas.
- All original backgrounds, the complete Italy map and16 local map images: aspect ratio retained, no crop; backgrounds fit1600px and maps2000px. WebP quality82.
- All16 local-map TypeScript data literals converted without executing code. Node/road IDs, percentage coordinates, starting nodes and internal road vertices are preserved. Original main-map COORDS, starting node and connections are also preserved in JSON.
- Currently imported character animation coverage: 37 species, 185 action atlases. The original tree contains37 animated forms and185 sheets (idle/attack/hit/victory/ko); the remaining73 species use static portraits. Every original frame, order and original24FPS timing is retained. Idle atlases use384×384 cells for clearer creatures; attack/hit/victory/ko use192×192 cells. Logical viewports are scaled proportionally, preserving identical displayed sizes and pivots across all five actions. All sheets retain full shared canvases and use WebP quality78. Only spatial downsampling/compression occurs; no frame generation, reversal, temporal interpolation or skipping.
- Eight existing Beta VFX sheets serve as type representatives through data/vfx.json; all game move IDs map to a type fallback. These upstream sheets were already generated in Beta, as its original catalog records; no new image generation was performed in this import. Both existing D6 transition images are reused.
